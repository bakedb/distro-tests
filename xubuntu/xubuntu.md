# Xubuntu

## Day 1
I just installed Xubuntu over Ubuntu Unity, and I was easily able to migrate my seperate home partition that I made. I am liking this already. Unlike with Unity, I have access to the preinstalled App Center, where I can easily browse available packages and one-click install them. This made installing VSCodium (yes, not VSCode this time. I learned my lesson) and Julia much easier. I still haven't tested if Julia will work, but things seem pretty good so far.

Now for the standout feature of Xubuntu: the desktop environment. Xubuntu is just the Xfce DE over Ubuntu, which is pretty obvious. By default, there is a taskbar on the top of the screen with a button on the far left with the Xubuntu logo that intuitively opens a menu with applications in it. Then there are all of your open applications. On the right, you have notifications, bluetooth, WiFi, battery, volume, time and date, and then the launcher. The launcher is where you can pin apps to quickly launch, which was not at first obvious to me. Think how the older Windows taskbars worked: there were icons that you could pin to open applications, and those applications would open seperately from the icon. I am liking Xfce so far, and the only hiccup I have had is not knowing about the launcher.

Xfce is *really* reminding me of the default DE on Raspberry Pi OS, which I used for pretty much a whole summer.

One thing that I have just found out about is that any file that you drag on to any app on the launcher, it will open with that app. This feature really reminds me of macOS.

So far within the first 20-ish minutes of me using Xfce, I think it might be one of my favorite DEs so far. However, that may just be because I am so familiar with it because I used a fork of it on Raspberry Pi OS for so long.
